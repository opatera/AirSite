AirSite

Private network home

Your server tools, library, and storage in one place.

AirSite is the front door to your home server: a clean landing page for storage, media playback, handheld games, and live machine status.

Everything stays centered on your own network, with AirServer as the file hub behind the rest of the experience.

What AirServer does
  • Lets users browse from `/share` downward without exposing directories above it.
  • Supports drag-and-drop or picker-based uploads.
  • Lets users download files and create folders directly from the browser.
6 Main tabs for storage, media, games, network, and system visibility.
1 Shared home page that keeps your private services grouped together.
0 Cloud dependency for the core experience once it is running on your LAN.
